# SUNDAYYY NAAAA I LOVEE YOUUU + + + — GitHub Pages Flipbook

This is the complete mobile-friendly flipbook based on the supplied PDF and scrapbook reference aesthetic.

## Included changes
- 32-page letter content based on the supplied PDF.
- Original scrapbook / cut-out magazine-letter visual style.
- Opening **MADE WITH LOVE / For Alaia** cover that physically opens when tapped.
- Swipe, tap, arrow-key and button page turning.
- Three independent song cards with their own artwork and their own file picker:
  - Never Leave Your Side — Saw Tooth Wave
  - Spring Into Summer — Lizzy McAlpine
  - Champagne Coast — Blood Orange
- Selecting/playing one track does not change pages or automatically switch to another track. Starting another track pauses the previous one so two songs do not overlap.
- The requested “kristie yarnz?” text is removed.
- Responsive layout for iPhone, iPad, Android and desktop browsers.
- Web-app manifest so it can be added to a phone/tablet home screen.

## Audio
The actual commercial recordings are **not bundled** in this public website package. The song cards are ready for an authorized local audio file: tap “choose file” on the corresponding card, then Play.

If you have permission to host the recordings publicly, place the authorized audio files in an `audio/` folder and change each card's JavaScript to use its corresponding URL instead of the file picker.

## GitHub Pages
1. Create a GitHub repository.
2. Upload **everything in this folder**, keeping `index.html` and `manifest.webmanifest` at the repository root and keeping the `images/` folder intact.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. GitHub will give you a Pages URL such as `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`.
7. Open that URL on Safari/Chrome. On supported phones/tablets, use **Add to Home Screen** to make it behave more like a standalone booklet.

## Important
GitHub Pages is public web hosting. Do not upload copyrighted audio recordings unless you have the rights/permission to make those recordings publicly available.
